# Pre-requisites
1) Python 3.10.x
2) UV Package Manager and Build tool
3) VS Code 

# Setup steps
1) Initialize virtual environment
```
uv venv --python 3.10
source .venv/bin/activate
```

2) Setup project
```
uv init
```

3) Setup dependencies
```
uv add -r requirements.txt
```
